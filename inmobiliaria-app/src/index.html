Falta un paso: actualizar la base de datos

Esta versión guarda datos nuevos (fotos de DNI, datos completos de inmuebles, conceptos del recibo, avisos, IPC). Hay que hacerlo una sola vez, desde cualquier PC:

  1. Tocá Copiar código.
  2. Entrá a supabase.com → tu proyecto → SQL Editor → New query.
  3. Pegá (Ctrl+V) y apretá Run. Tiene que decir "Success".
  4. Volvé acá y tocá Ya lo ejecuté.

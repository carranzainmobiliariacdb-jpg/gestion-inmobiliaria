# Gestión Inmobiliaria — Carranza Inmobiliaria

App de escritorio para administrar alquileres (Tauri + Supabase). El código
está en [`inmobiliaria-app/`](./inmobiliaria-app); ahí está el README completo.

Cada push que toque `inmobiliaria-app/` compila el instalador de Windows con
GitHub Actions, lo publica como Release y las PCs se actualizan solas.
